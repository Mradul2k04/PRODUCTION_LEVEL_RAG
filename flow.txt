=========================================================
                ASK MY DOCS - PROJECT FLOW
=========================================================

TECH STACK
---------------------------------------------------------
Frontend        : Streamlit
LLM             : Groq (Llama 3)
Embeddings      : Cohere
Vector Database : ChromaDB
Keyword Search  : BM25
Hybrid Search   : BM25 + Vector Search
Re-ranking      : Cross Encoder
Framework       : LangChain
---------------------------------------------------------


PHASE 1 : DOCUMENT INGESTION
=========================================================

User Uploads Documents
        │
        ▼
Document Loader
(document_loader.py)
        │
        ▼
Load PDF / DOCX / TXT
        │
        ▼
LangChain Documents
        │
        ▼
Text Splitter
(text_splitter.py)
        │
        ▼
Create Chunks
(chunk_size + overlap)
        │
        ▼
Cohere Embeddings
(embeddings.py)
        │
        ▼
Convert Chunks → Vectors
        │
        ▼
Chroma Vector Store
(vector_store.py)
        │
        ▼
Store:
    - Chunk Text
    - Embeddings
    - Metadata
        │
        ▼
Vector Database Ready
