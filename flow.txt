=========================================================
                ASK MY DOCS - PROJECT FLOW
=========================================================

TECH STACK
---------------------------------------------------------
Frontend        : Streamlit
LLM             : Groq (Llama 3.1)
Embeddings      : Cohere
Vector Database : ChromaDB
Keyword Search  : BM25
Hybrid Search   : BM25 + Vector Search
Re-ranking      : Cross Encoder
Framework       : LangChain
---------------------------------------------------------


PHASE 1 : DOCUMENT INGESTION
=========================================================

User Uploads Documents
        │
        ▼
Ingestion Pipeline
(ingest_pipeline.py)
        │
        ▼
Document Loader
(LoaderFactory)
        │
        ▼
Load PDF / DOCX / TXT
        │
        ▼
LangChain Documents
        │
        ▼
Text Splitter
(DocumentChunker)
        │
        ▼
Create Chunks
(chunk_size + overlap)
        │
        ▼
Cohere Embeddings
(EmbeddingFactory)
        │
        ▼
Convert Chunks → Vectors
        │
        ▼
Chroma Vector Store
(VectorStoreFactory)
        │
        ▼
Store:
    - Chunk Text
    - Embeddings
    - Metadata
        │
        ▼
Vector Database Ready

PHASE 2 : QUERY PROCESSING
=========================================================

        │
        ▼
RAG Pipeline
(rag_pipeline.py)
        │
        ▼
Load Vector Database
        │
        ▼
Hybrid Retrieval
(HybridRetriever)
        │
        ├──────────────►
        │               BM25 Retriever
        │               (Keyword Search)
        │
        └──────────────►
                        Vector Retriever
                        (Semantic Search)
        │
        ▼
Ensemble Retriever
        │
        ▼
Top-K Retrieved Chunks
        │
        ▼
Cross Encoder Re-ranking
(CohereReranker)
        │
        ▼
Sort Chunks by Relevance
        │
        ▼
Best Chunks Selected
